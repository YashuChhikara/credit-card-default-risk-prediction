# Credit Card Default Risk Prediction

This project predicts whether a credit-card customer will default on their payment next month.

## Tools Used
Python, Pandas, Matplotlib, Scikit-learn

## What I Did
- Cleaned and explored the dataset.
- Checked missing values, duplicates, invalid values, and class balance.
- Analyzed customer repayment and financial data.
- Built Logistic Regression and Random Forest models.
- Evaluated results using precision, recall, F1-score, confusion matrix, and ROC-AUC.
